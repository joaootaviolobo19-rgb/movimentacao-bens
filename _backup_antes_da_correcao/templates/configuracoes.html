Como funciona
  1. Configure SMTP (Gmail/Outlook).
  2. Escolha frequência, dia e hora.
  3. Adicione destinatários.
  4. Ative o switch "Ativar envio automático".
  5. Salve. O sistema verifica a cada 3 min se é hora.
  6. Use "Testar envio" para validar agora.
